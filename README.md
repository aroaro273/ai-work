# 오늘 운동하셨어요?

요일별 운동 계획을 세우고, 오늘의 운동과 지난 기록을 확인하는 웹앱입니다.

메뉴에서 **나의 일주일 운동**을 눌러 계획을 저장한 뒤, **오늘** 화면에서 마친 운동을 체크하세요. **결과**에서 기록을 볼 수 있습니다. 기록은 이 기기의 브라우저에 저장되며, 다른 기기로 자동 이동하지 않습니다. 브라우저 데이터를 삭제하면 기록도 지워질 수 있으니 설정에서 기록을 다운로드해 보관하세요.

GitHub Pages에 올릴 때는 이 폴더의 파일들을 저장소의 맨 위에 올리고, 저장소 설정의 Pages에서 배포할 브랜치와 루트 폴더를 선택하세요.

컴퓨터에서 미리 보려면 이 폴더에서 터미널을 열고 `미리보기.bat` 파일을 두 번 클릭하세요.
